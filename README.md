# Siteless — лиды без сайта

Telegram-бот для поиска клиентов на разработку сайтов: находит компании в городе,
у которых **нет своего сайта** (или есть только соцсеть), и выдаёт их списком
с телефоном, ссылкой на WhatsApp с готовым текстом, статусами и заметками.

> Данные берутся из **Geoapify / OpenStreetMap**


## Как это работает

1. `/search кафе Алматы` — бот находит город через Geoapify Geocoding и загружает
   до `MAX_PLACES` организаций нужной категории через Geoapify Places.
2. Компании фильтруются:
   - есть настоящий сайт → **отбрасывается**;
   - нет сайта и нет телефона → отбрасывается;
   - нет сайта, есть телефон → тип «без сайта»;
   - сайт — только соцсеть (Instagram, Telegram, WhatsApp, Taplink и т.п.) →
     тип «только соцсеть», показывается, только если включён `/social`;
   - при включённом `/mobile` остаются только мобильные номера Казахстана.
3. Компании с мобильным номером идут первыми. Результаты сохраняются в PostgreSQL
   и показываются по 5 на страницу с кнопками навигации.
4. У каждой компании есть ссылка на WhatsApp (только для мобильных номеров) с текстом
   из вашего шаблона и ссылка «проверить сайт» (поиск в Google), чтобы вручную
   убедиться, что сайта действительно нет.
5. Кнопка с номером переключает статус компании:
   📩 → ✅ написал → 💬 ответил → 🤝 клиент → ❌ отказ → 📩. К компании можно добавить
   заметку (`/note 3 перезвонить`). Компании со статусом в новых поисках не показываются,
   а `/pipeline` показывает воронку и компании в работе.

## Доступ

Владелец (`OWNER_ID`) пользуется ботом без ограничений. Остальные:

1. Пишут боту (Start или любое сообщение) — заявка создаётся сразу. Можно сначала оставить заявку на сайте.
2. Владельцу приходит сообщение с кнопками «Одобрить» / «Отклонить».
3. После одобрения бот сам пишет пользователю.

Ограничения для пользователей: до `DAILY_SEARCH_LIMIT` поисков в сутки (по умолчанию 10,
сутки по времени Алматы), поиск по всему Казахстану — только владельцу, работа только
в личных сообщениях. Заявки и пользователи — `/users`, закрыть доступ — `/revoke ID`.
После отказа повторную заявку можно отправить не раньше чем через сутки.

Иконка для бота лежит в `assets/bot-icon.png` (512×512) — загрузите её через @BotFather → `/setuserpic`.

## Установка

```bash
npm install
```

### 1. База данных

```bash
# macOS / Homebrew
brew services start postgresql

createdb leadfinder
```

Таблицы создаются автоматически при первом запуске бота
(та же схема лежит в [schema.sql](schema.sql), если хотите применить её вручную).

### 3. Запуск

```bash
npm start      # обычный запуск
npm run dev    # с автоперезапуском при изменении файлов
```

В консоли должно появиться `Бот запущен`. Список команд в меню Telegram
регистрируется автоматически.

## Команды бота

| Команда | Что делает |
|---------|------------|
| `/search <категория> <город>` | Поиск, напр. `/search кафе Алматы`, `/search салон красоты Шымкент` |
| `/search <категория>, <город>` | То же через запятую — удобно для городов из нескольких слов |
| `/search все Алматы` | Все категории сразу |
| `/business <город>` | Основные категории бизнеса (общепит, красота, автосервис, спорт, отели, медицина) |
| `/categories` | Список доступных категорий |
| `/social` | Вкл/выкл показ компаний, у которых только соцсеть |
| `/mobile` | Вкл/выкл режим «только мобильные номера» |
| `/template <текст>` | Изменить текст для WhatsApp. `{name}` заменяется на название компании. Без аргумента — показать текущий |
| `/note <номер> <текст>` | Заметка к компании из последнего списка. Без текста — удалить заметку |
| `/pipeline` | Воронка по статусам и компании со статусом «ответил» / «клиент» |
| `/export` | Выгрузить последний результат в CSV (разделитель `;`, UTF-8 с BOM — открывается в Excel) |
| `/last` | Открыть последний поиск (например, после перезапуска бота) |
| `/stats` | Число компаний со статусом, настройки, поиски за сегодня |
| `/clear` | Сбросить все статусы и заметки |
| `/help` | Справка |
| `/users` | Только владелец: заявки (с кнопками) и пользователи |
| `/revoke <ID>` | Только владелец: закрыть доступ |

Доступные категории: кафе, кофейня, ресторан, бар, фастфуд, парикмахерская,
салон красоты, аптека, отель, фитнес, автосервис, магазин, офис, образование,
бизнес, все. Добавить новую — дописать пару «название → категория Geoapify»
в объект `CATEGORIES` в [bot.js](bot.js)
([список категорий Geoapify](https://apidocs.geoapify.com/docs/places/#categories)).

## Хранение данных

| Таблица          | Что хранит |
|------------------|------------|
| `users`          | Настройки: `/mobile`, `/social`, шаблон WhatsApp |
| `leads`          | Найденные компании (общие для всех поисков) |
| `searches`       | История поисков: город, категория, время |
| `search_results` | Какие компании попали в какой поиск и в каком порядке |
| `contacted`      | Статусы компаний (`contacted`, `replied`, `client`, `rejected`) и заметки |
| `access`         | Заявки на доступ и одобренные пользователи |
| `search_usage`   | Сколько поисков пользователь сделал за день |

Открытая страница результатов хранится в памяти процесса. Если после перезапуска
кнопки отвечают «Результаты устарели», выполните `/last`.

Новые таблицы и колонки создаются сами при запуске бота (`CREATE TABLE IF NOT EXISTS`
и `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`), старые данные сохраняются.

## Сайт

В [src/](src/) — лендинг на Vue + Vite + vue-router + vue-i18n (RU/EN): описание бота,
макет чата, FAQ, форма заявки и страница «О нас». Бот от сайта не зависит.

```bash
npm run frontend   # dev-сервер (форма заявки локально не работает — нет /api)
npm run build      # сборка в dist/
npm run preview    # просмотр сборки
```

### Деплой сайта на Vercel

1. vercel.com → Add New → Project → импортировать репозиторий. Настройки уже в `vercel.json`.
2. Settings → Environment Variables: `API_TOKEN` и `OWNER_ID` — для формы заявки
   ([api/request-access.js](api/request-access.js) пересылает заявку владельцу в Telegram).
   Остальные переменные бота сайту не нужны.
3. Analytics → Enable, чтобы видеть посещаемость (`@vercel/analytics` уже подключён).

Превью ссылки (Open Graph) берёт адрес сайта сам; для своего домена задайте `SITE_URL`.

## Деплой бота на Railway

Vercel не подходит для бота: ему нужен постоянно запущенный процесс.

1. railway.com → New Project → Deploy from GitHub repo → этот репозиторий.
   Команда запуска уже в `railway.json` (`node bot.js`).
2. В проекте: New → Database → PostgreSQL.
3. В сервисе бота → Variables: `API_TOKEN`, `GEOAPIFY_KEY`, `OWNER_ID`,
   `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`, `DATABASE_SSL=false`
   (внутренняя сеть Railway без SSL), при желании `DAILY_SEARCH_LIMIT`.
4. Deploy. В логах должно появиться `Бот запущен`.

Бот работает через long polling, поэтому одновременно должен быть запущен только один
экземпляр: перед запуском на Railway остановите локальный `npm start`, иначе Telegram
вернёт ошибку 409 Conflict.

```text
schema.sql    — SQL-схема (то же, что создаёт initDb())

api/          — Vercel-функция формы заявки

```

## Частые проблемы

- **`API_TOKEN / GEOAPIFY_KEY / DATABASE_URL не задан в .env`** — нет `.env`
  или в нём пустое значение.
- **`OWNER_ID должен быть вашим числовым Telegram ID`** — указан не числовой ID
  (например, `@username`).
- **Бот отвечает владельцу «Бот закрытый…»** — `OWNER_ID` не совпадает с вашим ID.
- **Форма на сайте пишет «Не получилось отправить заявку»** — в Vercel не заданы
  `API_TOKEN` / `OWNER_ID`, или владелец ни разу не писал боту.
- **`409 Conflict: terminated by other getUpdates request`** — бот запущен в двух местах.
- **`ECONNREFUSED` / ошибка подключения к базе** — PostgreSQL не запущен
  или база из `DATABASE_URL` не создана.
- **`Город «…» не найден`** — попробуйте другое написание города; поиск
  сначала ищет в Казахстане.
- **Мало результатов** — в OpenStreetMap заполнены не все компании. Включите `/social`
  или попробуйте `/search все <город>`.
