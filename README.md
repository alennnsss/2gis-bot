# Siteless — лиды без сайта

Telegram-бот для поиска клиентов на разработку сайтов: находит компании в городе,
у которых **нет своего сайта** (или есть только соцсеть), и выдаёт их списком
с телефоном, ссылкой на WhatsApp с готовым текстом и отметками «написал».

> Данные берутся из **Geoapify / OpenStreetMap**


## Как это работает

1. `/search кафе Алматы` — бот находит город через Geoapify Geocoding и загружает
   до `MAX_PLACES` организаций нужной категории через Geoapify Places.
2. Компании фильтруются:
   - есть настоящий сайт → **отбрасывается**;
   - нет сайта и нет телефона → отбрасывается;
   - нет сайта, есть телефон → тип «без сайта»;
   - сайт — только соцсеть (Instagram, Telegram, WhatsApp, Taplink и т.п.) →
     тип «только соцсеть», показывается, только если включён `/social`;
   - при включённом `/mobile` остаются только мобильные номера Казахстана.
3. Компании с мобильным номером идут первыми. Результаты сохраняются в PostgreSQL
   и показываются по 5 на страницу с кнопками навигации.
4. У каждой компании есть ссылка на WhatsApp (только для мобильных номеров) с текстом
   из вашего шаблона и ссылка «проверить сайт» (поиск в Google), чтобы вручную
   убедиться, что сайта действительно нет.
5. Кнопка с номером (📩 → ✅) отмечает, что вы уже написали этой компании.
   Отметки хранятся в базе и переживают перезапуск.

Иконка для бота лежит в `assets/bot-icon.png` (512×512) — загрузите её через @BotFather → `/setuserpic`.

## Установка

```bash
npm install
```

### 1. База данных

```bash
# macOS / Homebrew
brew services start postgresql

createdb leadfinder
```

Таблицы создаются автоматически при первом запуске бота
(та же схема лежит в [schema.sql](schema.sql), если хотите применить её вручную).

### 3. Запуск

```bash
npm start      # обычный запуск
npm run dev    # с автоперезапуском при изменении файлов
```

В консоли должно появиться `Бот запущен`. Список команд в меню Telegram
регистрируется автоматически.

## Команды бота

| Команда | Что делает |
|---------|------------|
| `/search <категория> <город>` | Поиск, напр. `/search кафе Алматы`, `/search салон красоты Шымкент` |
| `/search <категория>, <город>` | То же через запятую — удобно для городов из нескольких слов |
| `/search все Алматы` | Все категории сразу |
| `/business <город>` | Основные категории бизнеса (общепит, красота, автосервис, спорт, отели, медицина) |
| `/categories` | Список доступных категорий |
| `/social` | Вкл/выкл показ компаний, у которых только соцсеть |
| `/mobile` | Вкл/выкл режим «только мобильные номера» |
| `/template <текст>` | Изменить текст для WhatsApp. `{name}` заменяется на название компании. Без аргумента — показать текущий |
| `/export` | Выгрузить последний результат в CSV (разделитель `;`, UTF-8 с BOM — открывается в Excel) |
| `/last` | Открыть последний поиск (например, после перезапуска бота) |
| `/stats` | Число отметок «написал» и текущие настройки |
| `/clear` | Сбросить все отметки «написал» |
| `/help` | Справка |

Доступные категории: кафе, кофейня, ресторан, бар, фастфуд, парикмахерская,
салон красоты, аптека, отель, фитнес, автосервис, магазин, офис, образование,
бизнес, все. Добавить новую — дописать пару «название → категория Geoapify»
в объект `CATEGORIES` в [bot.js](bot.js)
([список категорий Geoapify](https://apidocs.geoapify.com/docs/places/#categories)).

## Хранение данных

| Таблица          | Что хранит |
|------------------|------------|
| `users`          | Настройки: `/mobile`, `/social`, шаблон WhatsApp |
| `leads`          | Найденные компании (общие для всех поисков) |
| `searches`       | История поисков: город, категория, время |
| `search_results` | Какие компании попали в какой поиск и в каком порядке |
| `contacted`      | Отметки «написал» |

Открытая страница результатов хранится в памяти процесса. Если после перезапуска
кнопки отвечают «Результаты устарели», выполните `/last`.

## Частые проблемы

- **`API_TOKEN / GEOAPIFY_KEY / DATABASE_URL не задан в .env`** — нет `.env`
  или в нём пустое значение.
- **`OWNER_ID должен быть вашим числовым Telegram ID`** — указан не числовой ID
  (например, `@username`).
- **Бот отвечает «Нет доступа»** — `OWNER_ID` не совпадает с вашим ID.
- **`ECONNREFUSED` / ошибка подключения к базе** — PostgreSQL не запущен
  или база из `DATABASE_URL` не создана.
- **`Город «…» не найден`** — попробуйте другое написание города; поиск
  сначала ищет в Казахстане.
- **Мало результатов** — в OpenStreetMap заполнены не все компании. Включите `/social`
  или попробуйте `/search все <город>`.
